## 📌 Overview

This is the source code for my personal portfolio website, built with modern semantic HTML5, CSS3 glassmorphism, and vanilla JavaScript. It highlights my journey from high-reliability enterprise banking infrastructure (Commonwealth Bank of Australia) to cutting-edge Generative AI and Agentic system testing (Microsoft Copilot Team at HCLTech).

### 🚀 Key Features

- **Interactive Terminal UI**: Real-time inspection of core domains, system validation highlights, and personal passions (Carnatic classical music & chess).
- **Impact Metrics**: 4+ years industry experience, 15+ AI features validated, 8 Microsoft 365 platforms, and 20% test coverage boost.
- **Experience Timeline**: Detailed career progression covering both AI QA engineering and mainframe banking batch processing.
- **Competency Matrix**: Grouped skills across Frontier AI, Software Development, Tools & Automation, and Engineering Delivery.
- **Light / Dark Mode**: Built-in dynamic theme switcher with local storage persistence.
- **1-Click Quick Contact**: Instant clipboard copy for email/phone and direct mail client integration.
- **Direct Resume Download**: Bundled with a downloadable PDF resume.

## 💻 Local Development

To run this site locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Akshay-Balachandran/portfolio.git
   cd portfolio
   ```

2. **Open in browser:**
   - Double-click `index.html`, or
   - Use any static server (e.g., `npx serve` or VS Code Live Server).

---

## 🚢 Deploying to Vercel

1. Log in to [Vercel](https://vercel.com/).
2. Click **"Add New..."** → **"Project"**.
3. Select your GitHub repository: `Akshay-Balachandran/portfolio`.
4. Keep the default settings (Framework Preset: *Other*) and click **"Deploy"**.
5. Your portfolio will be live at a custom URL (e.g. `https://portfolio-akshay-balachandran.vercel.app`) in under 30 seconds!
